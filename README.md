# Credit Risk Classification Project

## Overview
This project uses machine learning classification models to predict loan default risk using financial and demographic data.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- KNN
- SVC
- Gaussian Naive Bayes
- Voting Ensemble

## Best Performing Model
Random Forest achieved the highest overall performance based on F1 Score and ROC-AUC.
